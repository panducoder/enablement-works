The formula

Cost per active user = annual licence cost ÷ number of reps who used the tool and completed something in the last 30 days.

Compare it with cost per seat (annual cost ÷ licensed seats). When usage is 40%, each active user costs 2.5 times the seat price. Count a rep as active only if they completed something: a module, a roleplay, a certification or a shared asset. Logins alone flatter the number.

What the number tells you

Low usage rarely means a bad tool. It usually means nobody had the hours to fill the tool with current content, build programs in it, launch them properly and chase completion. The tool was bought; the operations were not. Before your next renewal, ask what it would take to double active users, not which tool to switch to. Frequently asked questions

What is cost per active user for an enablement tool?

It is the annual licence cost divided by the number of reps who used the tool and completed something in the last 30 days. It shows what you really pay for each rep the tool reaches.

What counts as an active user?

A rep who completed something in the last 30 days: a module, a roleplay, a certification or an asset shared with a buyer. A login alone does not count.

What usage rate should an enablement tool reach?

As our rule of thumb, aim for at least 60% of licensed reps active each month for a core tool such as an LMS or content platform. Below 40%, fix the operations before you renew or switch.
