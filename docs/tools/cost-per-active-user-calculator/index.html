The formula

Cost per active user = annual licence cost ÷ reps who used the tool and completed something in the last 30 days.

Compare it with cost per seat (annual cost ÷ licensed seats). At 40% usage, each active user costs 2.5 times the seat price. Count a rep as active only if they completed something: a module, a roleplay, a certification or a shared asset. Logins alone flatter the number.

Frequently asked questions

What is cost per active user for an enablement tool?

It is the annual licence cost divided by the number of reps who used the tool and completed something in the last 30 days. It shows what you really pay for each rep the tool reaches.

What counts as an active user?

A rep who completed something in the last 30 days: a module, a roleplay, a certification or an asset shared with a buyer. A login alone does not count.

What usage rate should an enablement tool reach?

As our rule of thumb, 70% or more of licensed reps active each month is healthy for a core tool. Between 40% and 70%, find out which teams are inactive. Below 40%, fix the operations before you renew or switch.
